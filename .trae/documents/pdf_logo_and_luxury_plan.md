# PDF 报告 Logo 和高级感设计改进计划

## 一、需求分析

用户提出两个核心需求：

1. **Logo 全局化**：让 PDF 每一页都显示 logo（目前封面页和 section\_intro 页缺少 header）
2. **高级感设计**：提升报告整体视觉设计，营造"高贵"、"尊享"的感觉

### 当前设计风格评估

* **配色**：使用红(#B33A3A)、橙(#F4A261)、青(#2A9D8F)三色系统

* **字体**：PingFang SC / Microsoft YaHei

* **布局**：简洁现代风格

* **不足**：缺乏层次感、装饰元素和精致细节

## 三、改进方案

### 3.1 Logo 全局化

为以下页面添加统一的 header：

* **section\_intro（章节介绍）**：添加标准 header

* **cognitive\_details（认知详情）**：添加标准 header

* **backcover（封底）**：保持现状（底部已有logo）

### 3.2 高级感设计改进

#### 配色升级

* **主色调**：从红色(#B33A3A)升级为深邃酒红色(#5D2E46)或午夜蓝(#1A2A44)

* **金色点缀**：添加金色(#D4AF37)作为强调色，营造奢华感

* **背景质感**：使用微妙的纹理或渐变背景

#### 字体优化

* **标题字体**：使用更具质感的衬线字体（如 Noto Serif SC）

* **强调文字**：添加字间距和细字重

* **数字**：使用等宽字体，增强专业感

#### 装饰元素

* **页边装饰线**：添加细微的金色边框或装饰线

* **分隔线**：使用渐变或装饰性分隔线

* **水印效果**：添加低调的品牌水印

#### 排版提升

* **留白优化**：增加页面留白，提升呼吸感

* **层级分明**：通过字号、字重、颜色区分信息层级

* **精致细节**：添加微妙的阴影、圆角、过渡效果

## 四、实施步骤

### 步骤 1：修改 report.html - 添加全局 Header

为 cover、section\_intro、cognitive\_details 页面添加统一的 page-header

### 步骤 2：升级配色方案

在 report.html 的 `<style>` 区域更新颜色变量：

* 主色：`#5D2E46`（深邃酒红）或 `#1A2A44`（午夜蓝）

* 金色：`#D4AF37`（装饰强调）

* 辅助色：保持青色 `#2A9D8F` 和橙色 `#F4A261`

### 步骤 3：添加高级装饰元素

* 添加页面边框装饰

* 添加精致的分隔线样式

* 添加微妙的背景纹理

### 步骤 4：优化字体和排版

* 更新字体声明，添加衬线字体选项

* 调整标题字间距和字重

* 优化留白和内边距

### 步骤 5：生成测试并验证

运行 `generate.py` 生成 PDF，验证所有页面都有 logo，且视觉效果符合预期

## 六、风险评估

* **风险**：颜色变更可能影响现有视觉层级

* **应对**：保持核心数据可视化颜色不变，仅调整装饰性颜色

* **风险**：字体变更可能导致渲染问题

* **应对**：使用系统预装字体或 Web 安全字体

## 七、预期效果

完成后，PDF 报告将具有：

1. **统一的品牌识别**：每一页都显示 logo
2. **高级视觉体验**：金色点缀、精致装饰、充足留白
3. **专业质感**：衬线字体、等宽数字、层次分明的排版
4. **尊享感**：整体设计更显高端、精致
