# Leo E4 报告反馈落地 计划

## 背景

用 Leo（初一，2026-09-05 报告）在生产 /internal 跑出的 E4 协议（/Users/jefflau/Downloads/Leo_E4协议.md），
JSN 逐条批注。已与用户确认 4 个决策点。本计划只改 E4 框架规则与 AI prompt，不改 PDF/解读核心代码；
prompt_lab 本地页与 /internal 共用同一后端，规则改动两边同时生效。

## 已确认决策

1. 强/弱特质相对比较对认知 6 个分项（感知觉/注意力/记忆力/推理/空间/加工速度）都做标注，**仅作识别，不改变问题级 verdict**；
   只有出现错位组合（高感知觉 + 相对弱注意力 → 分心/粗心风险）时才影响判定。
2. 工作记忆 40 规则**保持现状**（有问题），不加确定性失真标注；AI 可在「待观察」段以施测疲劳作假设。
3. Step2 输出改为三段式，且**允许 AI 点名凭远内部工具**（如「一表人才」）。
4. 跟进线索**不写入协议文件**，只注入 AI prompt 影响分析文字。

## 调整清单（9 项）

### A. evaluation_rules.py — 框架与规则

1. **安全感问题只留依恋信任（E1）**
   - E4_FRAMEWORK「学生是否处在安全感中？」indicators 删去 `职业兴趣-常规型` 与 `安全稳定` order，
     仅保留信任-母亲/父亲/同伴三项。
   - 重写 `_v_e1_safety`：三项信任均为 高/不低 → 健康「依恋关系显示处于安全感中」；
     任一偏低 → 关注（不出 有问题，严重依恋问题由亲子问题承担）；删除原需求×缺失真值表。

2. **确定性需求移到计划性（E4）**
   - 「计划性」indicators 增加 `职业兴趣-常规型`、`安全稳定` order。
   - `_v_e4_planning`：责任心/自主性维持原判定；常规型与排序作上下文行（中性，不进 worst_state）；
     summary 在确定性需求成立（常规型不低/高 或 安全稳定前五）时追加
     「高确定性需求 + 计划性不足 → 结构化机制切入点」。

3. **认知基线两行进入 E3**
   - 「信息输入基本功能」indicators 前置 `认知能力总得分`、`认知能力百分位`（总，code 002）。
     两行从 OTHER_VARIABLES 自动移出（框架引用即保留）。
   - 新增 `_v_e3_input`：基线两行渲染为参照行（不参与问题判定，note 标「标准分」「认知总基线」）。

4. **强特质 / 相对弱特质标注（认知 6 分项）**
   - `evaluate_question_verdicts` 中取 `认知能力百分位`（code 002）为基线 B：
     - 分项 eval=高，或百分位 ≥ B+10 → item 注 `trait=强特质`
     - 百分位 ≤ B−10 → item 注 `trait=相对弱特质`（note：`总{B}，差值`）
   - 标注挂在 item 上（只对 003-008 六个认知分项），`_format_e4_line` 在 eval 后追加
     `强特质(总87,+12)` / `相对弱特质(总87,-18)`；[REF] 行不追加。
   - 不改变任何问题级 state（Leo 推理73/空间71 仍为中性）。

5. **分心错位组合（两处 verdict）**
   - 「信息输入基本功能」`_v_e3_input`：感知觉强特质 与 注意力相对弱特质 同时成立 → state=关注，
     summary「组内错位：感知觉强特质 vs 注意力相对弱特质（差XX），注意力值得关切」。
   - 「执行能力-专注力」新增 `_v_e3_focus`：注意力相对弱特质 + 感知觉强（抑制控制作参照行）→
     state=关注，summary「潜在分心组合：高感知觉+相对弱注意力，易粗心/分心，关注作业环境与电子产品管理」。

6. **第四组「基于表面的学习」改判错配**
   - `_v_e4_mismatch_surface`：记忆 mid/high（不低/好）+ 表面策略 low → 由「健康·不依赖表面方法」
     改为 **关注**，summary「错配（低垂果实）：记忆能力支持表面方法但表面策略偏低——有能力却没用表面方法」；
     与第三组深层策略对称。其余分支（记忆低+策略高等）保留。

7. **E2 精力行显示评级，避免 AI 误读得分**
   - `_v_e2` 已能从全量索引找到 优/良好/中等 评级；把评级写回 item（`pdf_grade` 字段），
     `_format_e4_line` 对体质习惯得分行追加 `评级:优`（即使 eval 为空也显示），
     Leo 饮食行将呈现 `饮食习惯得分 | 0 | 评级:优`。
   - 顺手修复 `思维模式结果` 行 raw 与档位重复显示（78.4 | 78.4 → 一个 78.4）。

### B. app.py — Step2 / Step3 prompt 与拼装

8. **Step2 输出三段式（`_e4_step2_system` 重写，step2/one-stop 两处共用）**
   - 保留：按维度逐问题的「判断：」段（JSN 确认格式好），仍以 Python 问题判定为准绳。
   - 删除原【跨维度连结】自由段，替换为三段：
     - **【显著问题】**：按干预优先级排序，每条附指标依据；区分真问题与需询证项。
     - **【可能失真·先观察】**：表面是问题但可能失真的数据（如工作记忆为施测末尾项可能受疲劳影响、
       自我概念-情绪状态可能受当下事件影响、E2 睡眠/饮食/运动待向 Gary/Jeff 核实），
       存在失真可能即先观察，不进直接干预。
     - **【跟进线索与切入点】**：数据支持的操作方向，**允许点名内部工具**。
   - prompt 内固化线索映射（来自 JSN 批注）：
     - 学习自我调节偏低 → 了解学生对各科老师的看法，与三级象限图学科投入位置交叉验证
     - 亲子亲近偏低（尤其母亲）→ 与测评解读师确认解读时是否提及该点
     - E2 睡眠/饮食/运动 → 向 Gary/Jeff 核实更新（运动关注项目类型，对照三级象限图运动投入）
     - 渴望成功动机成立 → 访谈「过去一年学习中有成就感的时刻」，动机从此切入
     - 分心组合 → 电子产品使用、做作业环境管理
     - 高确定性需求 + 计划性不足 + 策略使用少 → 可用「一表人才」做结构化学习机制并逐步养成习惯
       （prompt 内附一句话工具说明：结构化计划表/学习机制工具）
   - 硬规则新增：体质习惯「得分」与「评级」并存且冲突时以评级为准（饮食习惯 0 + 评级优 ≠ 饮食问题）。
   - 解析与拼装：step2/one-stop 中提取尾段的逻辑由「跨维度连结」改为新三段标题；
     `_assemble_e4_protocol` 的 `## E4_CROSS_DIMENSIONAL_ANALYSIS` 段改名 `## E4_ANALYSIS`，
     AI 全文原样放入（含逐问题判断 + 三段）。

9. **Step3 名单归属 AI 不得改判**
   - 把 Python 规则判定的 `list_placement.category` 注入 Step3 system prompt
     （prompt_lab step3 路由与 one-stop 路由两处）：AI 只写该归属的数据理由，禁止改判。
   - 修复 Leo 案例中 AI 自行判成「干预名单·强特质」、与规则「弱特质」矛盾的问题。

## Risks

- 特质阈值 ±10 为用户拍脑袋值：集中为一个常量（TRAIT_GAP=10），后续好调。
- 「一表人才」工具说明只写一句话，AI 点名时描述可能不充分；如产出不当再补工具背景。
- 认知基线进入「信息输入」组后，该组 verdict 必须显式排除基线两行（参照行），已在方案中处理。
