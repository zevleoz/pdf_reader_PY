# 学习动机与策略页面结构优化计划

## 需求分析

用户要求：
1. 删除页面顶部的 intro 文字
2. 去掉 slider 黑色圆圈内的数字，保留其他视觉元素
3. 重新结构化页面，使描述文字清晰地与对应的维度关联
4. 确保在一页内用满页面空间，更美观

## 方案设计

采用卡片式网格布局：
- **学习动机**部分：2列 × 3行卡片网格
- **学习方法与策略**部分：2列 × 3行卡片网格
- 每个卡片包含：维度名称（中英双语）、进度条、描述文字
- 卡片使用浅灰色背景（#F9FAFB）和边框，视觉上分组

## 修改文件

### 1. generate.py
- 删除 `build_page_14()` 中的 `intro` 参数
- 保持数据结构不变

### 2. templates/report.html
- 删除 intro 文字的渲染
- 重新设计模板结构，使用卡片网格布局
- 修改 `.value-dot span` CSS 隐藏数字
- 添加卡片网格相关 CSS 样式

## 实施步骤

1. **删除 intro 文字**：修改 `build_page_14()`，移除 intro 参数
2. **隐藏 slider dot 内的数字**：修改 CSS，设置 `.value-dot span { display: none; }`
3. **重构模板结构**：将6个维度改为卡片网格布局
4. **添加卡片样式**：浅背景色、边框、圆角
5. **测试验证**：运行 `python main.py` 生成 PDF，确认一页内显示完整

## 风险与注意事项

- 确保卡片网格在一页内完全显示，可能需要调整字体大小和间距
- 保持与其他页面的视觉风格一致

## 预期效果

- 描述文字与对应维度清晰关联（在同一个卡片内）
- 页面结构更清晰，视觉分组明确
- 充分利用页面空间，保持美观
