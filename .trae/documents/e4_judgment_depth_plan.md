# E4 逐问题判断加深 Implementation Plan

## Repository Research

用户反馈：Leo_E4协议-3.md 中每个问题的 AI 判断太短（多数只有 1 句），需要更充实、有 qualification 和 nuance。

当前 prompt 中导致输出过短的约束（app.py `_e4_step2_system`）：

1. **硬性句数上限（3 处重复，互相强化）**：
   - L2619-20：健康 1-2 句、有问题 2-4 句
   - L2652 语言风格：健康 1-2 句、有问题 2-4 句
   - L2664 输出格式：健康/中性 1-2 句、有问题/关注 2-4 句
2. **推理抑制**（L2652）：「不要每句都解释推理过程」被 AI 理解为只给结论。
3. **去重规则压缩后续问题**（L2621）：「之后的问题只写与本问题相关的新角度」——同一指标再次出现的问题（如专注力题、错配四组）被压到极简。
4. **guides 中的「一句」指令**（evaluation_rules.py L1468/1503/1511/1516）：学习自信、E2、信息存储、加工速度四条 guide 明确要求「一句话」/「一句带过」。
5. 只有长度上限，没有「深度内容应包含什么」的正向定义——AI 不知道多写该写什么。

约束：用户此前明确反对废话和重复，所以「多」必须是信息量，不是注水。bias=truth 等上一批改动保持不变。

## Files and Modules

- `app.py`：改 `_e4_step2_system()`（L2595-2674），统一句数指导、给深度正向定义、放宽后续问题去重约束。
- `evaluation_rules.py`：改 4 处含「一句/一句带过」的 guide（L1468、L1503、L1511、L1516），允许健康题有支撑性的第二句。

## Implementation Steps

1. **在 prompt 中新增「判断深度」正向定义**（替换三处重复的句数上限，只保留一处权威表述）：
   - 健康/中性：1-3 句。给结论 + 支撑模式（哪些指标互相印证），不展开。
   - 关注：3-5 句。包含：判断结论、qualification（在什么条件下成立/为什么档位标签不代表严重问题）、题内指标关系、对该生的实际含义。
   - 有问题：4-6 句。包含四要素（按数据情况自然组织，不机械列点）：
     1. 判断结论（问题是什么）
     2. 证据链（题内哪些指标共同支持，方向是否一致）
     3. 上下文含义（在这个学生的其他指标背景下意味着什么、实际可能表现为什么）
     4. 边界与把握度（什么情况会改变判断；仅在真不确定时写，bias 已标注的不写待确认）
2. **放宽去重规则 L2621**：同一指标在后续问题出现时，禁止重复已做过的解释，但该题仍需独立成段——写该题视角下的新分析层（该指标在这个问题里扮演的角色），不得只写一句引用。每题长度要求独立适用，不因指标重复出现而豁免。
3. **修改语言风格 L2652**：删掉「不要每句都解释推理过程」（过度抑制），改为「直接给判断，紧跟为什么；每一句都必须承载该生特有的信息，禁止教科书式通用解释和填充句」。
4. **改 4 条 guide**：
   - L1468 学习自信：方向一致时由「一句话给结论」改为「结论 + 一句指标互验」。
   - L1503 E2：全部健康时由「一句话收尾」改为「结论 + 一句整体精力模式」。
   - L1511 信息存储：不低时不展开，但给结论 + 一句对学习策略的支撑含义。
   - L1516 加工速度：同上，结论 + 一句对限时任务的含义。
5. 输出格式段（L2663-64）与去重段的句数表述同步为新的分级标准，消除三处不一致。

## Dependencies and Considerations

- 核心问题/跟进线索三段式、bias=truth、原始分优先、术语禁令等上一批改动不动。
- 判断加深会增加 step2 输出 token；30 个问题全部加深后估算输出 +600-1000 字，在模型上下文预算内，不影响调用结构（仍一次 step2）。
- 防注水是本次改动成败关键：靠「每句必须承载该生特有信息」「禁教科书解释」两道约束兜底。

## Validation

- `python3 -m py_compile app.py evaluation_rules.py`
- 用 Leo md 夹具跑 `_parse_e4_judgments` + `_assemble_e4_protocol`，确认归位与格式不回归。
- grep 确认 prompt 中不再有三处互相矛盾的句数上限、guides 中不再有「一句带过」。
- 实际深度效果需部署后用 Leo 真实跑一次 step2 验证（本地无 Leo DB），由用户确认。

## Risks

- **风险：AI 走向另一极端（注水/通用教科书化）** → prompt 明确每句须有该生特有信息；若真实输出仍注水，下一轮用反例（Leo 旧输出中的空话句）写进 prompt 做负例。
- **风险：后续问题为凑长度重复解释** → 去重规则保留（禁重复已做解释），只要求补「该题视角的新分析层」。
