# Y4 Report Generator — Phase 1: Split Layout + Production Deployment

## Scope: Phase 1 Only (Core)

Phase 1 目标：**上线现有核心功能** — 上传 4 份 PDF → 提取 → 生成报告 → 预览 & 下载。界面改为「左 1/3 上传 + 右 2/3 PDF 预览下载」的分栏布局。

**AI chatbox / AI 解读师功能不在 Phase 1 范围内。** 分 Phase 2 单独开发和部署（右栏 Tab 切换 + DashScope 模型 + 报告数据上下文）。

***

## 1. 架构（仍然：ECS 全栈，零 Vercel）

```
用户浏览器 report.你的子域名.com
    │
    ▼  HTTPS 443 (Let's Encrypt)
Nginx (端口 443 + 80 重定向)
    │
    ▼  Unix socket
Gunicorn 2 workers, timeout 600s
    │
    ├── GET / → templates/index.html (分栏 UI)
    ├── POST /api/generate → extract → validate → generate → PDF 二进制
    └── GET /output/report.pdf → iframe 内嵌预览 / 下载
```

### 1.1 为什么不用 Vercel

| 比较项     | ECS 全栈（本方案）                      | Vercel 前端                 |
| ------- | -------------------------------- | ------------------------- |
| 额外费用    | 0 元（ECS 已有）                      | Vercel 免费额度够用但无必要         |
| 跨域 CORS | 无（同源）                            | 有（Vercel 域名 != ECS IP/域名） |
| 维护部署    | 一套（Git pull + systemctl restart） | 两套 + CORS 头               |
| 稳定性     | 高（已验证本地可行）                       | 中（跨域 + 两套版本）              |

### 1.2 域名

**方式：使用你自己的子域名 → DNS A 记录 → ECS 公网 IP**

步骤：

1. 告诉我你的子域名（例如 `report.example.com`）
2. 在你的 DNS 服务商（阿里云域名、Cloudflare、DNSPod 等）添加一条 A 记录：

   ```
   主机记录：report （或你选的子域前缀）
   记录类型：A
   记录值：<阿里云 ECS 公网 IP>
   TTL：600
   ```
3. 服务器上执行：

   ```bash
   sudo certbot --nginx -d report.你的子域名.com
   ```
4. 完成：`https://report.你的子域名.com` 即可访问。

**作为备选（如果暂时不设置子域名）**：直接用 ECS 公网 IP + 端口 80 访问（`http://<IP>`），不加密，之后随时可加域名。

### 2.3 左栏：上传区

```
标题：📄 上传报告
提示：按报告标识上传。至少 1 份即可生成报告。

┌─ A2 ───────────────────────────────────┐
│  [A2 标签]            点击选择 PDF 上传 │
│  上传 A2 — 核心素养                      │
│  CORE LITERACY 子说明                    │
│  📎 已选择：file.pdf  |  📁 未选择      │
└──────────────────────────────────────────┘
  (同样4个：A2, B3, B4, B6)

── 思维模式分值（可选） ──
[ 输入 0-100 ]  分（0=固定 50=混合 100=成长）

[ 🚀 生成并预览报告 ] ← 大蓝按钮，禁用态=灰
  (文件数 ≥1 才启用)

[ 状态行: spinner + 文案 (约 1-3 分钟，请耐心等待) ]
```

### 2.4 右栏：预览 + 工具栏

**三种状态：**

**(1) 空状态（页面刚打开）：**

* 中央大号 PDF 占位图标 + 灰字说明：「上传报告并点击「生成报告」后，在此预览综合测评报告 PDF。」

**(2) 生成中状态：**

* 顶部工具条变灰，按钮禁用

* 中央：大号 spinner + 文案「正在生成，请耐心等待…」

* （可选）3 步骤提示：

  * ① 提取数据中…（30-120s）

  * ② 校验完整性…（<5s）

  * ③ 渲染 PDF…（5-15s）

* 通过进度条或分步显示视觉反馈

**(3) 已生成：**

* 工具条（左上：文件名 + 大小） / （右上：「↗ 新窗口打开」次要按钮 / 「⬇ 下载 PDF」主蓝按钮）

* 主体：`<object data="/output/report.pdf" type="application/pdf" width="100%" height="calc(100vh - 240px)">` 内嵌预览

* 回退：如果浏览器不支持内嵌 PDF，显示「浏览器不支持内嵌预览，请点击右上角下载」的提示

## 4. 验证步骤（部署后）

1. **子域名 DNS 生效后**：浏览器访问 `https://report.你的域名.com`
2. **左栏上传**：选 4 个 PDF 测试
3. **点生成**：观察状态 → 约 1-3 分钟
4. **右栏预览**：检查 PDF 是否正确显示（与本地版本对比页码/内容）
5. **下载按钮**：点击「下载 PDF」，保存后打开与本地生成一致
6. **新窗口打开**：点击「↗ 新窗口打开」，在新标签中完整查看 PDF
7. **错误测试**：上传无内容 PDF → 检查错误红色卡片弹窗是否清楚
8. **移动端：** 浏览器缩窄宽度 → 左右两栏应自动变为上下堆叠（响应式）

## 5. 风险 & 应对

| 风险                                       | 概率 | 应对                                                                                                                                                  |
| ---------------------------------------- | -- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| iframe PDF 预览部分移动端浏览器不支持                 | 中  | 降级为「点击下载按钮查看 PDF」并始终保留下载按钮                                                                                                                          |
| branding/ 图片路径第一次预览时找不到（从未跑 generate 的话） | 低  | 顶栏 Logo 改用 `/static/branding/logo_color.png` 路径；或者在部署后用 curl 跑一次 `POST /api/generate` 让 `generate.py` 把 `branding/` 复制到 `output/branding/`（之后就一直存在） |
| DNS 解析慢                                  | 低  | 先用 `http://ECS_IP` 访问验证，等 DNS 生效再用子域名                                                                                                               |
| 移动端分栏过窄                                  | 低  | 响应式断点 900px 以下切换为上下堆叠                                                                                                                               |
