## 框架结构核对结论

将新 guideline 与代码中 `E4_FRAMEWORK` 逐行比对：

* **E1（8 个问题）**：问题文本、指标集合**完全一致**。用户标注「自我效能感＝主维度」，代码目前无主次标记。

* **E3（11 个问题）**：**完全一致**（含「渴望成功」用成就感/声望地位排序 + 思维模式结果）。

* **E4（7 个问题，含错配四组）**：**完全一致**。

* **E2**：guideline 只列 睡眠习惯/饮食习惯/运动习惯/自我概念-躯体外貌 4 项；**代码中多出** **`体质健康-BMI`**（见待确认 Q-E2-1）。

结构层面唯一差异是 E2 的 BMI。新 guideline 的真正新增内容是**每个指标在具体问题下的判定语义**（阈值、方向、组合规则），目前代码里完全没有这一层——现有的 `eval_value` 是中性档位（高/较好/不低/偏低…），而 guideline 给的是「在该问题下算 有问题 / 关注 / 健康」的问题级判定，且同一指标在不同问题下语义不同（如 神经质高在通用档位里是「较好」，在「高敏感内耗」问题里是风险信号；胜任感的中间档在「自卑」问题里是「观察」）。

**Q3 亲子关系影响**

**Q4 整体自卑**
14\. 情绪稳定性-自卑自尊（011）：`<5 有问题，<10 未达标` → 需特殊关注(<5)=有问题 / 需关注(5-10)=未达标(关注级) / 相对健康(>10)=健康。

**Q5 焦虑**

**Q6 高敏感内耗**
19\. 人格-神经质（019）：`>3.5、>4 不同级别`，**方向反转**（档位越高越是风险）。**已确认 Q-E1-5**：神经质单独成立结论，>4 = 强风险信号，3.5-4 = 弱信号，≤3.5 无显著。现有规则 3.5-4.5 都标「较好」，不能直接用档位判，需要问题级反转判定。

**Q7 不开心**

| 干预名单强/弱 | **按问题严重度分**：强特质=问题表现强烈（需特殊关注/明显偏低/多个 E1 问题同时成立）→ 重点干预；弱特质=轻度问题（单一「有问题」或多为「关注」/OBSERVATION）→ 轻量干预/观望 |
| 潜能名单强特质 | 学习力顶尖 + 心力无问题 + 精力无弱。量化线（用户定义）：**认知百分位总体平均 ≥95**（002-008 认知能力-×百分位各项平均）、**执行功能 ≥90**（063-065 三项平均）、**心力无问题**（E1 八问无 PROBLEM verdict）、**精力无弱**（睡眠/饮食/运动评级无差/低）。霍兰德有维度≥7 作**加分标注**（兴趣优势），非必要条件 |
| 潜能名单弱特质 | 心力/精力无问题，但学习力潜力或动力不充分 → 潜能名单中不满足强特质线者 |

已闭环缺口：
- 认知 95 = **总体平均**（002-008 平均）
- 执行功能 90 = 三项平均（不在现有档位边界上，强特质判定直接用 raw_value）
- 精力 = 无弱即可（中等可接受）
- 霍兰德≥7 = 加分不必要
- Q-E4-1 错配 = 按初步理解编码：
  - 一/二组（数理逻辑/空间）：自评能力优势与实测百分位**不一致=错配**——自评不低(≥4)但实测偏低(<60)=自我认知偏差（高估）；实测不低(≥60)但自评偏低(<4)=低估自己
  - 三组（理解学习）：推理≥60 但深层策略偏低=错配（**低垂果实**）；推理<60 但深层策略不低+=方法超出能力支撑
  - 四组（表面学习）：记忆<60 但表面策略不低+=依赖表面但记忆弱（**更危险**）；记忆≥60 但表面策略偏低=不依赖表面方法
