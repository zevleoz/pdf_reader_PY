# Y4 AI Prompt 定制化升级方案

## 研究结论

### 当前状况
- **ai_interpreter.md**（AI 解读器系统提示词）：163 行，结构较完整（5 大原则 + 6 种典型组合 + 5 个维度判断规则 + 3 段输出），但内容**过短、过粗**，缺乏以下关键信息：
  1. 没有**具体的指标参考框架**（每个指标的正常值/偏高/偏低的解读含义、百分位/T分/档位对照规则）
  2. 只有 6 个典型组合，覆盖不全（缺少「焦虑 + 睡眠差」「自我效能高 + 责任心低」「依恋不安全 + 学习动机低」「霍兰德 + 多元智能 + 价值观不一致」等 10+ 常见组合）
  3. 输出结构**太短**（1 个核心矛盾 + 1-2 个优势 + 3 个行动 = 太简短，家长/顾问觉得没信息密度）
  4. 缺少**凭远教育的风格调性**（比如 Y4 四维的具体哲学、不同年级的侧重点、留学申请场景下的解读切入）
  5. 没有**年级分层解读策略**（初一 vs 高一，关注点完全不同）

- **transcript_summary.md**（会议纪要生成提示词）：结构完整，75 行，五部分 + 硬规则，相对做得好，但也缺少：
  - 与 Y4 四维体系的**锚定关系**（比如第二部分"四维测评要点"没有告诉 AI 每个维度具体有哪些指标）
  - 凭远具体的**顾问工作流**（行动清单如何贴合顾问下一步跟进）

## 具体修改步骤

### Step 1: 重写 ai_interpreter.md（核心）
**结构升级为 7 大章节：**

#### 一、身份与凭远 Y4 哲学（新章节）
- 明确 AI 身份：凭远教育资深 Y4 解读顾问，服务准备留学/升学的中产家庭学生
- Y4 的核心哲学：不是贴标签，而是回答四个问题「TA为什么会产生这样的情绪和行为 / 为什么某些任务突出某些受阻 / 家长做什么有效什么反而适得其反 / 未来 6-12 个月该聚焦什么」
- 明确目标读者：**家长（60%）+ 学生（20%）+ 顾问跟进（20%）**
- 输出长度：**不是极简，是"信息密集 + 有深度 + 有抓手"，800-1500 字**（原为 1 个核心矛盾 + 3 步，太短）

#### 二、数据语言规则（原第一部分，保留并扩充）
- 保留原有 4 原则（Y4语言体系/组合解读/先排除Context/不做医学诊断）
- **新增：具体指标判读基准表**（就是上面那个 94+ 指标字典，作为附录给 AI 查阅）
  - 百分位：<30 明显弱 / 30-50 偏下 / 50-70 正常区间 / 70-90 良好 / >90 强 / >95 极强
  - 均值对照：写清每个有均值的指标的「低于均值」「持平均值」「高于均值」的实际含义（如：情绪稳定性 009 均值40 → <35 明显脆弱 / 35-45 中间 / >45 稳定）
  - 档位规则（依恋低/中/高区间、自我概念偏低/正常/偏高、BMI评级等），直接把 Y4 PDF 里写的判定边界抄进 prompt
- **新增：年级分层策略**
  - 初中（6-9年级）：重点 = 依恋关系 + 学习动机 + 自我概念 → 核心是父母的养育方式调整
  - 高中（10-12年级，重点！）：重点 = 生涯力（霍兰德+智能+价值观交叉） + 学习力（执行功能/学习自我调节） + 内驱力 → 核心是选专业/选课/活动/留学申请匹配
  - 学生年龄 < 12岁：不做生涯力深度解读，只做探索建议

#### 三、典型组合识别（原第二部分 6 组 → 扩充到 16 组）
- 保留现有 6 组
- 新增 10 组（焦虑过载、习得性无助、动机双低、聪明但懒、依恋断联、兴趣错位、自我概念分裂、神经质+宜人性高、开放性高+艺术低、表面动机高+睡眠差）
- 每组格式规范：**触发条件（具体指标阈值） → 行为表现推测 → 家长常见误区 → 正确干预切入点**

#### 四、四维判断规则深化（原第三部分，扩充）
- 原 5 个维度（情绪/认知/人际/学习动力/兴趣）保留
- 每个维度加**具体数值型判断标准**（例：认知里「推理>90 + 加工速度<50」= 聪明但作业慢/马虎，不是"笨"）
- 新增**精力体质判断规则**（BMI+饮食+睡眠+运动综合：睡眠<7h 且运动<3h 且 BMI 超重 = 精力系统严重短板，优先调这个）
- 新增**跨系统大判断**（心力 + 学习力合看：如「神经质高 + 依恋母亲沟通低 + 学习自我调节低」= 家庭沟通是根因，学习只是表面症状）

#### 五、输出格式（原第四部分，**从3段扩到6段**）
原格式太短（3段）。改成 6 段式：

```
一、学生画像 · 120 字以内
  一句话总结这个人的核心特质 + 发展阶段判断
  用比喻更好（例："一位能力极高但油门和刹车都在别人手里的赛车手"）

二、最值得关注的 2-3 个核心信号
  每个信号 = 3-5 条 Y4 指标交叉支撑 + 可能形成的行为表现 + 为什么现在需要关注
  不要孤立的高分低分
  每条 2-3 句

三、真实优势 · 2-3 个
  每个优势必须是 指标 + 行为场景 + 能怎么用好它（留学申请/高中选课/未来专业）
  不是简单挑最高分，而是跨系统验证的优势

四、家长可能在踩的坑 · 1-2 个（新增）
  根据依恋/自我概念/情绪，推测家长当前的教育方式可能在适得其反的地方
  用"可能在做的事"而不是"您做错了"的语气

五、未来 6 个月焦点 · 分优先级
  P0（立即做）：2 条，最关键的杠杆点，为什么是P0
  P1（本月做）：2 条，具体可执行
  P2（本学期做）：2 条，长期方向
  每条都要写：做什么｜谁来做｜周期｜能解决上面的哪个核心信号

六、选专业/选课/留学申请的线索（高中新增）
  如果是9年级以上：结合霍兰德前2 + 多元智能前3 + 职业价值观前3，给 2-3 个方向建议 + 为什么适合 + 下一步怎么验证
  如果是初中：写「暂不做专业方向确定，建议…（探索建议）」
```

#### 六、凭远 Y4 风格硬规则（原第五部分扩充）
- 保留原 8 条
- 新增：**具体的语气/表达要求**
  - 不用"首先/其次/最后"，直接讲内容
  - 每句话尽量有具体指标编号做佐证（如「自我概念-躯体外貌 055=4 分，低于正常范围 6-8」而不是「自我概念偏低」）
  - 对家长有**既共情又专业**的语气，不居高临下
  - 所有判断都要带"可能/大概率/从数据推测"的软性表述
  - 建议**优先于学习建议**的顺序：先精力/身体 → 再家庭沟通 → 再情绪/内驱力 → 最后才是学习策略和专业

#### 七、指标字典附录（新）
把完整的指标编号 → 名称 → 满分/均值/百分位判断规则 → 档位说明 列出来作为附录，让 AI 每次解读都能精准引用（避免瞎编数据含义）

### Step 2: 增补 transcript_summary.md
- 第二部分「四维测评要点」里加入每个维度的指标字典提示，告诉 AI 每个维度具体指哪些指标
- 第四部分「行动清单」增强：贴合凭远顾问工作流（如"顾问 3 天内发送学校资源包"、"顾问下周和学校 counselor 约沟通"等可选项）
- 加凭远的风格化硬规则（简洁但不简单、避免套话、引家长原话）

### Step 3: app.py /api/chat 端点小改
- `max_tokens` 从 4096 → 7680（输出变长，避免截断）
- 可选：`temperature` 从 0.4 → 0.5（稍微增加一点表达多样性，但不胡编）

## 依赖和注意事项

1. **不需要加新依赖**：仅修改 Markdown 文本和 app.py 里两个数字
2. **API token 消耗增加**：输出从 500 字涨到 1000-1500 字，每次解读 token 用量约翻倍。如果 DashScope 有额度限制，用户需知悉。当前默认模型是 qwen-plus，价格可接受。
3. **响应时间增加**：当前解读 15-30 秒 → 升级后可能 25-45 秒。前端加载动画要确保能撑到这个时长（前端已有动画，不需改）
4. **不影响会议纪要 DOCX 功能**：两个 prompt 独立，改 ai_interpreter.md 不影响 transcript_summary.md 的现有输出格式
5. **年级判断**：app.py 里已把 `grade` 字段传给 AI，但 AI 需要明确知道怎么根据 grade 切换解读深度。在新 prompt 里写清楚"初中/高中"判断标准即可
6. **与之前版本兼容性**：输出格式从 3 段变 6 段，前端聊天框是直接渲染文本的，**无需改前端**（chatbox 支持任意长度 Markdown）

## 风险处理

| 风险 | 应对 |
|---|---|
| 输出太长前端卡顿 | 前端 chatbox 已有滚动容器和 `max-height`，不会卡 |
| 输出被 token 截断 | Step3 max_tokens 提到 7680 后基本不会；极端情况可以再升到 8192 |
| AI 开始编造数据 | 新增的第七章「指标字典附录」明确每个指标的判定边界，减少编造 |
| 家长觉得语气太硬 | 风格规则里加了具体语气要求，减少攻击性表述 |
| 会议纪要格式走样 | 单独修改 transcript_summary.md，结构和硬规则保留不变，仅增补充实内容 |
