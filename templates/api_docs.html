概述

本 API 提供 Y4 综合测评报告的只读访问。所有端点位于 /api/v1/ 前缀下，使用 GET 方法，需通过 API Key 认证。

Base URL: https://your-domain/api/v1

认证方式

所有请求必须在 HTTP 头中携带 API Key：

Authorization: Bearer YOUR_API_KEY

缺少或无效的 API Key 将返回 401。未在服务端配置 API Key 时返回 503。

获取 API Key：请联系凭远教育管理员获取你的专属 API Key。请妥善保管，不要在前端代码中暴露。

速率限制

默认每 IP 每分钟 60 次请求。超出限制时返回 429。限制可由服务端管理员调整。

跨域 (CORS)

API 默认允许所有来源 (*) 的跨域请求。生产环境建议管理员将允许来源限定为你的网站域名。浏览器跨域请求需显式携带 Authorization 头，不会自动发送凭据。

1. 学生列表

GET /api/v1/students

获取所有学生列表，包含报告数、纪要数、最新报告日期等摘要信息。

响应示例

{
  "ok": true,
  "students": [
    {
      "id": 1,
      "name": "张三",
      "grade": "初三",
      "school": "某中学",
      "advisor_name": "李老师",
      "report_count": 2,
      "minutes_count": 1,
      "latest_report_date": "2026-09-15"
    }
  ]
}

2. 学生报告列表

GET /api/v1/students/{student_id}/reports

获取指定学生的所有报告列表，按创建时间倒序排列。

路径参数

参数类型说明
student_idint学生 ID（从学生列表获取）

响应示例

{
  "ok": true,
  "reports": [
    {
      "id": 42,
      "report_date": "2026-09-15",
      "pdf_path": "output/report_张三.pdf",
      "created_at": "2026-09-15T10:30:00",
      "interpretation": "..."
    }
  ]
}

3. 报告元数据

GET /api/v1/reports/{report_id}

获取单份报告的元数据（不含原始数据全量，用于确认报告存在性和基本信息）。

路径参数

参数类型说明
report_idint报告 ID（从报告列表获取）

响应示例

{
  "ok": true,
  "report": {
    "report_id": 42,
    "student_id": 1,
    "student_name": "张三",
    "grade": "初三",
    "report_date": "2026-09-15",
    "has_interpretation": true
  }
}

4. Y4 JSON 数据

GET /api/v1/reports/{report_id}/y4-json

导出 Y4 JSON v2.0 格式报告，包含四维数据点（心力/精力/学习力/生涯力）、常模参照、AI 解读。适用于程序化处理。

响应结构

字段说明
json.meta学生元信息（姓名、年级、日期等）
json.dimensions四维数据：心力、精力、学习力、生涯力
json.norm_references常模参照数据
json.ai_interpretationAI 解读原文（Markdown 字符串）

响应示例

{
  "ok": true,
  "json": {
    "meta": {
      "student_name": "张三",
      "grade": "初三",
      "report_date": "2026-09-15"
    },
    "dimensions": {
      "心力": { "items": [...] },
      "精力": { "items": [...] },
      "学习力": { "items": [...] },
      "生涯力": { "items": [...] }
    },
    "norm_references": [...],
    "ai_interpretation": "## 核心发现\n..."
  }
}

5. Y4 Markdown 报告

GET /api/v1/reports/{report_id}/y4-md

下载人类可读的 Y4 报告 Markdown 文件，包含学生信息 + 四维已确认数据 + AI 解读原文。

查询参数

参数默认说明
include_raw0设为 1 在报告中包含原始数据值

响应

返回 text/markdown 附件下载，文件名格式：Y4报告_姓名.md

6. PDF 报告下载

GET /api/v1/reports/{report_id}/pdf

下载 Y4 评测报告 PDF 文件。

响应

返回 application/pdf 附件下载，文件名格式：Y4报告_姓名.pdf

注意：如果 PDF 文件在服务器上不存在（可能已被清理），将返回 404。

7. E4 评估协议

GET /api/v1/reports/{report_id}/e4-protocol AI 生成

生成并下载 E4 评估协议 Markdown 文件。包含跨维度 AI 分析、问题级判定、总览成文。每次调用都会实时调用 AI 模型生成。

查询参数

参数默认说明
include_raw0设为 1 在协议中包含原始数据值

响应

返回 text/markdown 附件下载，文件名格式：E4协议_姓名.md

注意：此端点会实时调用 AI 模型（Step2 跨维度分析 + Step3 总览成文），响应时间通常为 10-30 秒，请设置足够的超时时间。E4 协议与 Y4 报告是两套独立体系：Y4 面向内部同事阅读，E4 面向 AI 系统间传递。

快速开始

# 获取学生列表
curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://your-domain/api/v1/students

# 下载 Y4 JSON
curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://your-domain/api/v1/reports/42/y4-json

# 下载 Y4 Markdown（含原始数据）
curl -H "Authorization: Bearer YOUR_API_KEY" \
     -o Y4报告.md \
     "https://your-domain/api/v1/reports/42/y4-md?include_raw=1"

# 下载 PDF
curl -H "Authorization: Bearer YOUR_API_KEY" \
     -o report.pdf \
     https://your-domain/api/v1/reports/42/pdf

# 生成 E4 协议（响应较慢，建议设超时）
curl -H "Authorization: Bearer YOUR_API_KEY" \
     --max-time 120 \
     -o E4协议.md \
     https://your-domain/api/v1/reports/42/e4-protocol
const API_KEY = 'YOUR_API_KEY';
const BASE = 'https://your-domain/api/v1';

const headers = { 'Authorization': `Bearer ${API_KEY}` };

// 获取学生列表
const res = await fetch(`${BASE}/students`, { headers });
const { students } = await res.json();

// 下载 Y4 JSON
const jsonRes = await fetch(`${BASE}/reports/42/y4-json`, { headers });
const { json: y4Data } = await jsonRes.json();
console.log(y4Data.dimensions);

// 下载 Y4 Markdown
const mdRes = await fetch(`${BASE}/reports/42/y4-md?include_raw=1`, { headers });
const mdText = await mdRes.text();

// 下载 PDF（触发浏览器下载）
window.open(`${BASE}/reports/42/pdf?token=${API_KEY}`, '_blank');
// 注意：浏览器原生 fetch 下载文件建议用 Blob
const pdfRes = await fetch(`${BASE}/reports/42/pdf`, { headers });
const blob = await pdfRes.blob();
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url; a.download = 'Y4报告.pdf'; a.click();

# 生成 E4 协议（响应较慢，设超时 120s）

    f.write(r.content)

错误码

状态码含义
401API Key 缺失或无效
404报告不存在或 PDF 文件丢失
429请求频率超出限制
503服务端未配置 API Key

所有错误响应均为 JSON 格式：

{ "ok": false, "error": "错误描述信息" }
