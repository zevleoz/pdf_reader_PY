概述

本 API 提供 Y4 综合测评报告的只读访问。所有端点位于 /api/v1/ 前缀下，仅支持 GET 方法，并通过 API Key（服务端环境变量 Y4_API_KEY）认证，与后台管理员登录体系相互独立。

生产 Base URL：https://report.p4learning-ark.app/api/v1
该地址经 Cloudflare Tunnel 提供，自 2026-09-26 起取代旧直连 IP / 旧域名。请勿再使用任何占位符或旧 IP，必须使用上述真实地址。

共提供 8 个端点：1 个无需鉴权的健康检查 + 7 个需 API Key 的数据端点。

认证方式

除 /api/v1/health 外，所有请求必须在 HTTP 头中携带 API Key：

Authorization: Bearer YOUR_API_KEY

缺少或无效的 API Key 返回 401（错误码 UNAUTHORIZED）；服务端未配置 Y4_API_KEY 时返回 503（错误码 SERVICE_UNAVAILABLE）。

关于 API Key：Y4_API_KEY 是服务端环境变量，与具体服务器无关——服务器迁移后仍然有效，无需重新申请。请联系凭远教育管理员获取你的 API Key。切勿在前端代码、公开仓库或客户端日志中暴露，应仅在服务端读取。

速率限制

默认每 IP 每分钟 60 次请求。E4 协议端点（/api/v1/reports/{report_id}/e4-protocol）因实时调用 AI 模型，单独限制为每 IP 每分钟 8 次。超出限制返回 429（错误码 RATE_LIMITED）。限制均可由服务端管理员调整。

跨域 (CORS)

API 默认允许所有来源（*）的跨域请求，便于本地开发联调。生产环境强烈建议管理员通过环境变量 Y4_API_CORS_ORIGINS 将允许来源限定为接入方的具体域名。

* 的风险：允许任意来源意味着任何网站都可以在用户浏览器中调用本 API；一旦 API Key 泄露，攻击者可从任意前端直接发起请求。收紧为具体域名可大幅缩小暴露面。浏览器跨域请求需显式携带 Authorization 头，浏览器不会自动发送凭据（Cookie 默认不随 * 跨域携带）。

0. 健康检查

GET /api/v1/health 无需鉴权

公开端点，用于接入方验证服务连通性与基本可用性。不消耗默认限流配额，不要求 API Key。

响应字段

字段类型说明
okbool固定为 true
statusstr服务状态，正常为 healthy
servicestr固定为 y4-api
versionstrAPI 版本，当前 v1
timestr服务器时间，ISO 8601 字符串

响应示例

{
  "ok": true,
  "status": "healthy",
  "service": "y4-api",
  "version": "v1",
  "time": "2026-09-28T10:30:00+08:00"
}

错误码

本端点不返回业务错误码；仅在网络层或服务彻底不可用时返回 5xx。

1. 学生列表

GET /api/v1/students

获取所有学生列表，包含报告数、最新报告日期等摘要信息。仅返回外部接入所需的最小字段集；联系方式等敏感 PII（邮箱、电话、单亲标识、顾问姓名等）不在本端点返回。

响应字段

字段类型说明
idint学生 ID
namestr学生姓名
gradestr年级
schoolstr学校
report_countint该学生的报告总数
latest_report_datestr|null最新报告日期，格式 YYYY-MM-DD；无报告时为 null

响应示例

{
  "ok": true,
  "students": [
    {
      "id": 1,
      "name": "张三",
      "grade": "初三",
      "school": "某中学",
      "report_count": 2,
      "latest_report_date": "2026-09-15"

错误码

UNAUTHORIZED（401）· RATE_LIMITED（429）· SERVICE_UNAVAILABLE（503）

report_datestr报告日期，YYYY-MM-DD

响应示例

{

GET /api/v1/reports/{report_id}/y4-md

下载人类可读的 Y4 报告 Markdown 文件，包含学生信息 + 四维已确认数据 + AI 解读原文。

路径参数

参数类型说明
report_idint报告 ID（正整数）。<=0 或非整数返回 400 BAD_REQUEST

查询参数

参数类型说明
include_rawstr是否包含原始数据值，取值集合 {0, 1, true, yes, false, no}，默认 0。非法值返回 400 BAD_REQUEST

响应

返回 text/markdown 附件下载，文件名格式：Y4报告_姓名.md

错误码

UNAUTHORIZED（401）· BAD_REQUEST（400，report_id 或 include_raw 非法）· NOT_FOUND（404）· RATE_LIMITED（429）· SERVICE_UNAVAILABLE（503）

6. PDF 报告下载

GET /api/v1/reports/{report_id}/pdf

下载 Y4 评测报告 PDF 文件。

路径参数

参数类型说明
report_idint报告 ID（正整数）。<=0 或非整数返回 400 BAD_REQUEST

响应

返回 application/pdf 附件下载，文件名格式：Y4报告_姓名.pdf

路径安全：报告文件按 report_id 在受控目录内查找，文件名由服务端拼接学生姓名生成，report_id 经整数校验，避免路径穿越。若 PDF 文件在服务器上不存在（可能已被清理或未生成），返回 404 NOT_FOUND。

错误码

UNAUTHORIZED（401）· BAD_REQUEST（400）· NOT_FOUND（404）· RATE_LIMITED（429）· SERVICE_UNAVAILABLE（503）

7. E4 评估协议

GET /api/v1/reports/{report_id}/e4-protocol AI 生成

生成并下载 E4 评估协议 Markdown 文件。包含跨维度 AI 分析、问题级判定、总览成文。

路径参数

参数类型说明
report_idint报告 ID（正整数）。<=0 或非整数返回 400 BAD_REQUEST

查询参数

参数类型说明
include_rawstr是否包含原始数据值，取值集合 {0, 1, true, yes, false, no}，默认 0。非法值返回 400 BAD_REQUEST

缓存行为

服务端按 (report_id, include_raw) 缓存生成结果，TTL 约 10 分钟。同一参数在 TTL 内且对应报告的 interpretation 未变更时再次请求，直接返回缓存内容，不再调用 AI，节省模型计费。

响应头含义
X-Cache: HIT命中缓存，未调用 AI，响应快
X-Cache: MISS首次生成 / TTL 过期 / interpretation 变更后重新调用 AI

响应

返回 text/markdown 附件下载，文件名格式：E4协议_姓名.md

调用注意：首次或重新生成时需实时调用 AI（跨维度分析 + 总览成文），响应时间通常为 10-30 秒，请将客户端超时设置为 ≥120 秒。E4 协议与 Y4 报告是两套独立体系：Y4 面向内部同事阅读，E4 面向 AI 系统间互操作。AI 调用失败时返回 503 AI_UNAVAILABLE，且不写入缓存。

错误码

UNAUTHORIZED（401）· BAD_REQUEST（400）· NOT_FOUND（404）· RATE_LIMITED（429）· SERVICE_UNAVAILABLE（503）· AI_UNAVAILABLE（503）

错误码

所有 /api/v1/* 端点的错误响应均为统一 JSON 信封：

{ "ok": false, "code": "ERROR_CODE", "error": "人类可读描述" }
错误码HTTP含义
UNAUTHORIZED401API Key 缺失或无效
BAD_REQUEST400路径或查询参数非法（如 student_id / report_id 非正整数，include_raw 取值越界）
NOT_FOUND404报告不存在或 PDF 文件丢失
RATE_LIMITED429请求频率超出限制
SERVICE_UNAVAILABLE503服务端未配置 API Key 或服务不可用
AI_UNAVAILABLE503E4 协议 AI 调用失败

错误响应示例

{
  "ok": false,
  "code": "UNAUTHORIZED",
  "error": "Missing or invalid API key"
}

迁移与连通性排查

旧地址已废弃：旧直连 IP 120.55.0.127 及旧直连域名自 2026-09-26 起失效不可达。请尽快迁移至新生产地址 https://report.p4learning-ark.app/api/v1。

连通性自检

依次执行以下 curl，确认连通与鉴权正常：

# (a) 健康检查，无需 Key，期望 200
curl -i https://report.p4learning-ark.app/api/v1/health

# (b) 带 Key 访问受保护端点，期望 200
curl -i -H "Authorization: Bearer YOUR_API_KEY" \
     https://report.p4learning-ark.app/api/v1/students

常见失败原因与处理

现象原因处理
DNS 无法解析 report.p4learning-ark.app未使用 Cloudflare DNS 或本地 DNS 缓存过期使用 Cloudflare 公共 DNS（1.1.1.1），或刷新本地 DNS 缓存
直连旧 IP 返回 403（ICP/Beaver 拦截）阿里云对直连 IP 的未备案访问拦截该拦截仅作用于直连阿里云 IP；Cloudflare Tunnel 已绕过——请使用域名而非 IP
Cloudflare 首次连接略慢（~0.8s）Tunnel 首包建链正常现象，无需处理；后续请求会更快
401 UNAUTHORIZEDAPI Key 错误或缺失核对 Authorization: Bearer <KEY> 头格式与 Key 值
503 SERVICE_UNAVAILABLE服务端未配置 Y4_API_KEY 环境变量联系凭远教育管理员确认服务端 Key 已配置并已重启

密钥保管与轮换

  • 不要将 API Key 写入前端代码、提交到代码仓库或记录在客户端日志中；应在服务端通过环境变量或密钥管理服务读取。
  • 轮换流程：由凭远教育管理员修改服务端 Y4_API_KEY 环境变量并重启服务即可生效；建议与接入方协调切换窗口，避免轮换瞬间出现短时 401。
  • 泄露处置：一旦怀疑 Key 泄露，立即通知管理员轮换，并排查访问日志。
  • 按接入方独立 Key：当前暂不支持，所有接入方共用同一 Y4_API_KEY；按接入方独立 Key 与配额为后续规划项。

重试与幂等

  • 所有端点均为 GET，幂等且安全可重试。
  • E4 协议端点：遇 503 AI_UNAVAILABLE 应在退避后重试；缓存命中（X-Cache: HIT）的响应安全可重复获取。
  • 遇 429 RATE_LIMITED 应遵守退避，建议指数退避 1s / 2s / 4s，最多重试 3 次。
  • 客户端超时建议：普通端点 ≥30 秒；E4 协议端点 ≥120 秒。
