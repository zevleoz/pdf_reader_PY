# 6AM 思维导图 v0.6（2026-10-28）

## A1 自主感
- 状态
  - 稳固：自主性 高
  - 关注：自主性 不低
  - 风险：自主性偏低，或关注 + 独立自主前 5
    - 会谈证实
      - 阻塞
        - 被强压：独立自主 + 上司关系 同进前 5，掌控感 1–5
        - 学业挤占：抑郁愉快低，学习自我效能感低，学业自我概念相对低

## A2 认同感
- 学习
  - 稳固：深层动机 高
  - 关注：深层动机 不低
  - 风险：深层动机偏低，或关注 + 表面动机不低及以上 / 家长补充
    - 会谈证实
      - 阻塞：厌学
        - 常被批评：自我概念-行为表现
        - 被孤立：合群 + 归属感
        - 成绩差：学业自我概念 + 学习自我效能感，成就感排前时更明显
        - 不认同课堂 / 老师：学习自我调节
- 学习以外：First Touch
  - 稳固：认同（喜欢 + 擅长）
  - 关注：部分认同
  - 风险：不认同
  - 追问：时间主要花在哪
  - 类型
    - 兴趣空白型：霍兰德六型全低
    - 兴趣错位型：时间花在不喜欢的事上
- 取较重的一边

## A3 可用空间
- 状态
  - 稳固：身体、情绪、时间都没问题
  - 关注：最差的维度到关注
  - 风险：最差的维度到风险
    - 身体或情绪在风险 + 时间排满 / 会谈证实
      - 阻塞
- 类型
  - 恢复不足型：身体（睡眠 / 运动 / 饮食）
    - 稳固：都在优
    - 关注：任一不在优
    - 风险：任一差，或都不在优
  - 情绪消耗型：情绪
    - 稳固：总分 49–60
    - 关注：总分 25–48
    - 风险：总分 24 及以下，或任一子项低于 5 分
  - 时间过满型：时间
    - 风险：会谈证实排满
  - 认知（参考）：工作记忆 / 认知灵活性 偏低

## A4 胜任信心
- 状态
  - 两项：学习自我效能感 · 胜任感
  - 稳固：两项都高
  - 关注：都不偏低，且不都高
  - 风险：任一偏低
    - 会谈证实
      - 阻塞
        - 自卑 + 焦虑
        - 安全稳定 前 5
        - 能力高、自评低（同一能力比）
        - 自我概念 偏低
        - 掌控感 1–5
        - 思维模式 50 及以下
        - 神经质 高
        - 成就感 + 安全稳定 前 5
- 类型
  - 认知偏差型：能力前 25%，自评低
  - 评价焦虑型：自卑、焦虑 都需关注
  - 怕出错型：思维模式 50 及以下 + 自卑需关注
  - 低自我效能型：其余

## A5 可起步性
- 状态
  - 稳固：三型都稳固
  - 关注：最差的一型到关注
  - 风险：最差的一型到风险
    - 会谈证实 / First Touch 追问未通过
      - 阻塞
- 类型
  - 不愿尝试型：排斥新事物
    - 稳固：开放性 3.5 及以上
    - 关注：开放性 低于 3.5
    - 风险：开放性低于 3.5 + 安全稳定前 3 / 认知灵活性偏低
    - 参考：思维模式 50 及以下 · 宜人性高会掩盖
  - 拆解困难型：不会拆、不会计划
    - 稳固：自我调节、深层策略 都高
    - 关注：都不偏低，且不都高
    - 风险：任一偏低，或关注 + 责任心偏低
  - 易分心型：容易被拽走
    - 稳固：抑制控制 高
    - 关注：抑制控制 不低
    - 风险：抑制控制 偏低

## A6 启动支持
- 看 Y4：起点
  - 支持来源
    - 导师主动联系：外倾性 偏低
    - 同伴支持：同伴信任高 / 归属感好 / 外倾性高；同伴信任低不用
    - 家长陪同：亲子沟通 不低；亲子沟通低不用
  - 支持方式
    - 结构化拆解：常规型 高
    - 固定检查点：宜人性 高；焦虑需关注慎用
    - 小目标 + 及时反馈：掌控感 1–5
    - 私下低压尝试：自卑 + 焦虑 / 神经质高 / 安全稳定前 3
    - 公开承诺 / 适度竞争：成就感或声望前 5；焦虑或自卑需关注不用
    - 成人肯定与鼓励：自我概念 偏低

    - 意义连接
  - A2 学习 风险
    - 外部奖励：少用
  - A3 ≥ 关注
    - 减负 / 优先级
  - A3 身体或情绪 ≥ 关注

  - A4 ≥ 关注
