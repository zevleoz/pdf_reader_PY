# 6 A.M. 六维启动模型 · v0.3（内部讨论版）

> 本文只保留内部讨论需要的内容：模型怎样判断、Y4 已有什么线索、Y4 还缺什么证据、为什么必须追问。
> Y4 结果是初筛线索，不是学生结论；追问只在答案会改变判断或支持方式时使用。

## 1. 模型与判定流程

**模型回答：到底是什么挡住了学生迈出第一步？**

| 层 | 维度 | 核心问题 |
|---|---|---|
| 动机层：要不要做 | A1 自主感 Autonomy | 这是我想做的吗？ |
| 动机层 | A2 认同感 Alignment | 这件事对我有意义吗？ |
| 执行层：能不能做 | A3 可用空间 Availability | 我现在还有空间做吗？ |
| 执行层 | A4 胜任信心 Assurance | 我相信自己做得到吗？ |
| 执行层 | A5 可起步性 Accessibility | 我知道第一步怎么走吗？ |
| 支持层：怎么支持 | A6 启动支持 Activation Support | 什么样的支持能让我更容易开始？ |

**判定流程**

```
Y4 初筛：记录测评事实、初步假设和证据缺口
  ↓
First Touch：只追问会改变判断的问题，补充会谈观察、家长反馈和任务测试
  ↓
单维判断（state + 亚型 + 可信度）→ 跨维规则修正
  ↓
输出：处理顺序 / 支持方式 / 仍需确认的问题
```

**State 与可信度**

| 项目 | 用法 |
|---|---|
| Secure 稳固 | 当前证据未提示障碍，不干预 |
| Watch 关注 | 有弱信号或信号矛盾，需要验证 |
| At-Risk 风险 | 证据较一致，很可能影响启动，需要支持 |
| Blocked 阻塞 | 不先处理该维度，其他推进很难有效 |
| Hypothesis 假设 | 只有 Y4 或单一线索，尚未验证 |
| Supported 有佐证 | 有会谈观察、任务表现、家长反馈或顾问记录支持 |
| Confirmed 已证实 | 学生本人在追问中确认 |

State 表示阻碍程度，亚型表示“是哪一种阻碍”，两者都可随新证据更新，不是给学生定性。可信度低不代表问题轻，只代表还需要验证。

## 2. 六个维度：线索、缺口与必问问题

### A1 自主感：这是学生自己的选择吗

| 要判断什么 | Y4 已有线索 | Y4 缺口与必问问题 | 答案如何改变处理 |
|---|---|---|---|
| 任务是否真正属于学生 | 自驱力-自主性、无力感掌控感偏低（R1.1/R1.5） | **Q1.1**「这个项目最开始是谁的主意？你当时第一反应是啥？」Y4 看不到任务提出过程和学生的真实接受度 | 成人强加 → 先恢复选择权；学生自己想做 → 转查 A2/A3/A4/A5 |
| 是否高叛逆风险 | 独立自主进前 5，且自主性偏低或掌控感偏低（R1.3，A1-S2） | **Q1.4**「爸妈安排的事里，有多少是你自己本来也想做的？」用于验证“想自主但没空间”是否存在于真实生活 | 长期被要求且缺少重合 → 成人先让渡决定权；其实有不少自主空间 → 不直接判逆反 |
| 能否表达拒绝，反抗是外显还是隐性 | 宜人性、亲子依恋提供表达方式的背景 | **Q1.3**「不想做一件事，你会直接说出来，还是先答应着再说？」Y4 看不到学生实际如何拒绝 | 能直接拒绝 → 协商任务；只能先答应 → 检查被动抵抗或压抑顺从 |
| 是被动抵抗还是真心接受 | 自主性偏低且宜人性较高（R1.2，A1-S1） | **Q1.2**「假如明天老师说这事儿不用做了，你是偷偷松口气，还是有点可惜？」用于区分表面答应和真实意愿 | 松口气 → 支持被动抵抗判断；可惜 → A1 可能不是主因 |
| 是否无需干预 | 自主性、亲子依恋、幸福与满足正常（R1.6）；或独立自主未进前 5 且自主性正常（R1.8） | 无需因 Y4 单项结果额外追问 | 常规推进，不为“给选择权”而给选择权 |

**支持方式**：恢复所有权。提供有限选择、共同制定任务、允许修改目标。逆反型先让渡部分决定权；家长不让权的家庭按 X.7 处理。

### A2 认同感：这件事对学生有什么意义

| 要判断什么 | Y4 已有线索 | Y4 缺口与必问问题 | 答案如何改变处理 |
|---|---|---|---|
| 动力缺失还是外部动机硬撑 | 深层、表层动机双低（R2.3，A2-S4）；或深层低、表层不低（R2.4，A2-S2） | **Q2.2**「你做这件事图啥？这个理由是别人告诉你的，还是你自己真这么觉得？」用于确认动机来源 | 没有自己的理由 → 先建立意义；完全靠外部压力 → 减少硬撑，防止动机绷断 |
| 是任务错位还是内容不认同 | 霍兰德有高峰，但任务类型不匹配（R2.2，A2-S1） | **Q2.1**「如果这事跟升学没关系，你还会想弄吗？哪块有意思，哪块纯属折磨？」Y4 看不到学生对具体任务部分的感受 | 只排斥部分形式 → 调整任务形式；整个内容都不想 → 重新评估活动方向 |
| 是否全局无兴趣 | 霍兰德六型全部偏低（R2.1）；家长“没兴趣、没动力”主诉可交叉验证（R2.8） | **Q2.5**「最近有没有啥时候，你突然觉得『哎，这个有点意思』？不一定非得是学习上的。」测评全低可能只是填答状态 | 能举出真实兴趣 → 不判全局无兴趣；学生和家长证据一致 → 先兴趣探索，暂缓推任务 |
| 任务是否连接学生的价值 | 任务可连接的价值观均不在前 5（R2.5） | **Q2.4**「这事要是真做成了，你觉得自己能得到啥？」用于寻找学生自己的价值连接点 | 能说出个人价值 → 用该价值设计任务；说不出且不愿做 → 不强行包装意义 |
| 是否存在真实的主动投入 | Y4 没有既往兴趣行为记录（R2.7） | **Q2.3**「有没有什么事是没人催你、你自己就一直捣鼓下去的？」这是测评无法替代的行为证据 | 有同域经历 → 作为兴趣和方向的重要证据；没有 → 不把测评兴趣当成已验证事实 |
| 任务形式是否需要调整 | 开放性偏低（R2.6） | 无需单独追问，不据此判风险 | 使用更明确、熟悉、确定的任务形式 |

**支持方式**：找到学生自己的理由，而不是替他包装意义。全局无兴趣必须经学生和家长等证据交叉验证。

### A3 可用空间：学生现在还有空间吗

| 要判断什么 | Y4 已有线索 | Y4 缺口与必问问题 | 答案如何改变处理 |
|---|---|---|---|
| 睡眠与恢复是否已经影响容量 | 睡眠、运动、饮食评级（R3.1/R3.2） | **Q3.1**「你最近一般几点睡？第二天上课扛得住吗？」评级看不到当前作息和白天影响 | 已影响白天状态 → 先恢复，不急着加任务；只是测评偏低但状态稳定 → 保持观察 |
| 是否因情绪消耗而过载 | 焦虑安详、抑郁愉快、情绪稳定性总分（R3.3/R3.4，A3-S1） | **Q3.2**「如果现在跟你说『咱再加个新任务』，你心里第一反应是啥？」用于识别对新增任务的防御性排斥 | 明显抗拒或疲惫 → 先减负；反应平稳 → 继续核实其他维度 |
| 是否认知负荷过高 | 工作记忆或认知灵活性偏低，情绪相对稳定（R3.5，A3-S3） | 通过会谈和任务表现观察多步骤信息是否容易混乱，不另设重复问题 | 容易混乱 → 减少并行任务、增加外部结构 |
| 现实中是否真的没有执行空间 | Y4 没有日程、课程和自由时间数据（R3.6） | **Q3.3**「你一般啥时候能喘口气？那点时间你一般干嘛？」用于补全真实排期 | 无自由时间 → 先腾空间；仍有可用时间 → 不把所有拖延都归为容量问题 |
| 空间可以怎样腾出来 | 上述任一容量风险成立 | **Q3.4**「要真开始做这件事，你觉得得先把啥事儿放一放？」该问题直接决定减负方案，不用于贴标签 | 能指出可删事项 → 共同调整；没有任何可让渡事项 → 讨论延迟启动 |

**支持方式**：腾出空间。删除、合并、降级或延迟任务，先恢复睡眠和精力。A3 有风险时优先处理，A4/A5 结论待复评。

### A4 胜任信心：学生是否敢开始

| 要判断什么 | Y4 已有线索 | Y4 缺口与必问问题 | 答案如何改变处理 |
|---|---|---|---|
| 学生害怕的具体是什么 | 自我效能感、胜任感、掌控感、自我概念偏低（R4.1/R4.2/R4.6/R4.7） | **Q4.1**「如果这事最后没做好，你脑子里第一个蹦出来的念头会是啥？」用于区分能力否定、他人评价或其他担忧 | 怕证明“我不行” → 早期成功；怕被批评 → 评价焦虑路径；担心其他后果 → 不强行归为信心问题 |
| 失败后是回避还是能够恢复 | 自卑自尊需关注、思维模式偏固定型（R4.3）；Y4 没有既往失败行为（R4.8） | **Q4.2**「上次你试了个新东西结果搞砸了，后来你还碰它了吗？」用于获得真实失败后的行为证据 | 一次失败就放弃 → Draft 0、陪跑；能继续尝试 → 不直接判完美主义回避 |
| 是评价焦虑还是能力怀疑 | 焦虑安详与自卑自尊均需关注（R4.4，A4-S3） | **Q4.4**「假如前三次尝试谁都看不见，只有你自己知道结果，你会不会更敢上手？」用于区分两种原因 | 私下更敢做 → 私密、低压力尝试；仍不敢 → 继续检查能力和任务难度 |
| 自我认知是否偏离实际 | Y4 没有学科实际表现与自评的对照（R4.9，A4-S4） | **Q4.5**「你觉得自己最强的学科是哪个？咱拿最近几次成绩对对。」需与成绩或教师反馈对照 | 自评明显低于实际 → 校准信心；自评高于实际 → 另行记录，不用 A4 解释 |
| 是否对负面结果更敏感 | 神经质较高（R4.5） | 只是背景线索，无需单独判风险 | 降低高压力评价，不据此认定学生不敢开始 |

**支持方式**：创造早期成功。降低第一步难度、允许低质量初稿、提供示范和陪跑，用真实完成建立信心。

### A5 可起步性：学生知道第一步吗

Y4 没有 Task Initiation / Planning 子项，只能初筛，不能单独确诊规划障碍或启动障碍。

| 要判断什么 | Y4 已有线索 | Y4 缺口与必问问题 | 答案如何改变处理 |
|---|---|---|---|
| 是否已有具体的第一步 | 责任心、自我调节、深层方法与策略提供间接线索（R5.1/R5.5） | **Q5.1**「要是明天就得开工，你猜你第一个小时会干啥？」用于检验第一步是否具体存在 | 完全说不出 → 先共同设计第一步；说得很具体 → 继续查启动结构或信心 |
| 是规划障碍还是启动障碍 | 上述指标只能提示，不能区分两类障碍 | **标准化任务测试**：现场拆解一个大任务；能拆出后是否承诺第一步和开始时间（R5.7） | 拆不出 → A5-S1，提供拆分；拆得出但不开始 → A5-S3，提供外部结构 |
| 是否依赖外部结构 | 深层动机和自主性正常、自我调节偏低（R5.3，疑似 A5-S3） | **Q5.4**「以前有人带着做和自己一个人搞，感觉差在哪儿？」用于验证结构是否真的改变启动表现 | 有人带明显更好 → 安排时间、地点、流程和陪伴；差别不大 → 寻找其他原因 |
| 是选择过载还是没有兴趣 | 开放性较高、多个兴趣方向不低、方向未定（R5.2，A5-S2） | **Q5.3**「现在这几个方向，你是挑花眼了不知道选哪个，还是其实都不太想选？」用于区分 A5 与 A2 问题 | 想选但选不出 → 收敛选项；都不想 → 回到 A2 |
| 是否只需风险提示 | 抑制控制偏低（R5.4）；注意力偏低（R5.8） | 不重复设置深度干预问题 | 缩短第一步、减少干扰；注意力问题只预警并按需转介 |

**支持方式**：设计第一步。小、具体、马上能做、不需要完整准备，做完自然带出下一步。

### A6 启动支持：什么帮助真正有效

A6 不判断风险，而是根据前五维结论和学生真实反应选择支持方式。

| 要判断什么 | Y4 已有线索 | Y4 缺口与必问问题 | 答案如何改变处理 |
|---|---|---|---|
| 同伴协作是否有效 | 外倾性、同伴依恋较高（R6.1/R6.2） | **Q6.1**「你干得最顺的那些事，是一个人闷头干的，还是跟别人一起的？」测评外向不等于同伴有效 | 协作明显更顺 → 同伴协作排前；独立更顺 → 不强行安排小组 |
| 谁能形成有效问责 | 宜人性、依恋和 A5 结构依赖提供线索（R6.3/R6.7） | **Q6.2**「有没有那么一个人，TA 在等你的结果，你就不好意思不干？这人是谁？」用于确定有效支持者和合法支持来源 | 能指出具体人物 → 评估由其提供问责；没有 → 不随便指定家长或老师监督 |
| 死线和结构是否真有效 | A5 结构依赖、宜人性提供线索 | **Q6.4**「DDL 对你是真管用，还是只会让你焦虑到躺平？」用于区分结构支持与压力反噬 | 能推动行动 → 使用明确结构；只引发焦虑 → 降低压力、改用小步反馈 |
| 要认可还是要空间 | 成就感、声望地位、神经质和焦虑提供线索（R6.4/R6.5） | **Q6.3**「你努力的时候，是希望别人看见给你点赞，还是别盯着你、等出结果了再说？」用于选择 Recognition 或 Privacy | 希望被看见 → 及时认可；希望保有空间 → 减少围观和公开承诺 |
| 成人监督是否反而构成阻力 | A1 逆反或压抑顺从（R6.6）；家长陪同还需父母依恋和 A1 状态支持（R6.8） | 沿用 A1 已确认证据，不另设重复问题 | A1 受损时慎用权威施压和家长陪同 |

**支持方式**：输出“推荐方向 + 避免/慎用清单”，明确谁、以什么方式出现，而不是统一写“需要监督”。

## 3. 跨维规则与处理顺序

| 规则 | 何时使用 | 怎么处理 |
|---|---|---|
| X.1 A1 与 A2 同时受阻 | “被安排”和“不认同”同时存在 | 先恢复 A1 所有权，再讨论 A2 意义 |
| X.2 A2 信号可能受 A1 污染 | A1 为逆反型，A2 证据又全部来自成人安排的任务 | 不直接判内容不认同；用学生自选任务重测 |
| X.3 A3 优先 | A3 ≥ At-Risk | 先处理容量；A4/A5 的假设待 A3 处理后复评 |
| X.4 A4 约束 A5 | A4 ≥ At-Risk | 第一步必须低风险：可私下完成、允许低质量、无即时评价 |
| X.5 A6 兼容检查 | 推荐任何支持方式前 | 检查是否与前五维状态冲突，避免支持本身成为障碍 |
| X.6 全局无兴趣优先探索 | A2-S3 已经交叉验证 | 暂缓任务级干预，先兴趣探索 |
| X.7 家长不让权 | 家长无法或不愿让渡主导权 | A1 调整为长期目标；当前在家长边界内建立 A2 意义连接 |

**处理顺序**

1. Blocked → At-Risk → Watch；同级中，有行为证据的排在只有假设的前面。
2. A3 有风险时先处理 A3。
3. A1/A2 同时有风险时先 A1 后 A2。
4. 已确认全局无兴趣时，先兴趣探索。
5. 家长不让权时，A1 降为长期目标。

高优先级障碍暂定义为：Blocked，或已有行为证据支持的 At-Risk。

## 4. First Touch 与追问选择

**会前**

- 上传 Y4，逐维记录“已有线索 / 初步假设 / 证据缺口”；
- 收集家长主诉，供交叉验证；
- 不需要等待官方 Y4 解读。

**会中**

1. 核对关键 Y4 自评是否准确；
2. 了解既往主动投入和兴趣经历；
3. 按证据缺口追问，不逐项问完整个题库；
4. 对照学科自评与实际表现；
5. 询问真实日程、睡眠和自由时间；
6. 必要时进行标准化任务测试。

**标准化任务测试**：给一个真实量级的大任务，例如“两周完成一篇 2000 字研究小论文”，请学生现场说明安排。观察能否拆出步骤、能否承诺第一步和开始时间；情绪反应只作旁证，不单独定论。

**追问选择规则**

- 只问能够验证当前假设、区分两种解释或改变支持方式的问题；
- 已有充分证据的问题不重复问；
- 每个需要关注的维度至少保留一个问题；
- A6 支持偏好保留 1–2 个问题；
- 一次建议选择 8–10 题，按对话自然顺序进行，不按题号机械询问。

**会后**：更新各维 state、亚型、可信度、支持方式和剩余问题。
