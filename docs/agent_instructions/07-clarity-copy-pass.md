## P1 — 影响真实使用

### [P1-1] 校验错误引用整段题干，多题未答时不可读

- 位置：`questionnaire_engine/schema.py` `validate_answers()`（约 line 68-130），错误格式为 `第「{完整题干}」题：必填`
- 现象：46 题的问卷若漏答 10 题，错误列表是 10 条完整题干的堆叠，学生在 alert 里根本找不到是哪题
- 修复：
  1. `validate_answers` 的错误引用**题号**而非题干。函数内按 `questions_of(schema)` 的枚举顺序取序号 N，错误改为 `第 N 题：需要作答` / `第 N 题：至少选择一项` / `第 N 题：超过字数上限` / `第 N 题：取值需在 {min} 到 {max} 之间`
  2. 注意保持函数签名与返回类型（List[str]）不变；`questionnaire_engine/tests/` 若有断言旧文案的测试，同步更新
- 验证：构造一份漏答第 3、7 题的提交 → 错误恰为「第 3 题…」「第 7 题…」两条

### [P1-2] 作答校验失败用浏览器原生 alert() 堆叠错误

- 位置：`templates/student/q_form.html` line 163-168（`alert(msg)`，errors 以 `\n` 拼接）
- 现象：原生 alert 无品牌、无格式、长文本不可读；家长手机上体验差
- 修复：改为**内联错误横幅**——表单顶部（进度卡下方已有 `s-alert` 位）显示"还有 N 题未完成：第 3、7、12 题"，点击题号滚动到对应题目并高亮（题目块加短暂描边闪烁类）。提交按钮下方不再依赖 alert；网络异常保留简洁内联提示"网络异常，请检查网络后重试"
- 保留：`submit()` 的 busy 防重复、JSON 提交与无 JS 原生表单降级逻辑不动

## P2 — 本轮修完

### [P2-1] 「提交成功」页也显示「前往登录」按钮（误导）

- 位置：`templates/student/message.html` line 7（无条件渲染 `前往登录` 链接按钮）；调用方在 `blueprints/questionnaires.py` line 432-491
- 现象：一次性链接提交成功后，页面是"提交成功 + [前往登录]"——链接模式的学生根本没有账号，按钮把他们引向一个进不去的登录页
- 修复：`message.html` 增加条件参数 `show_login`（默认 False）；只有"链接无效/链接已过期/任务不存在"等需要引导登录态的场景才传 `show_login=True`；"提交成功""问卷已提交"页面改显示静态文案"你可以关闭本页了"，不给按钮
- 顺带统一：message 页 title/message 见下表

| 场景 | 现状 | 改为 |
|---|---|---|
| 提交成功 | 提交成功 / 你的问卷已提交，感谢作答。+ [前往登录] | 提交成功 / 问卷已收到，感谢作答。你可以关闭本页了。 |
| 任务不存在 | 任务不存在 / 任务已不存在，请联系顾问。 | 链接已失效 / 该作答链接已失效，请联系顾问重新获取。 |
| 链接无效 | 链接无效 / 该作答链接无效或已被替换，请联系顾问重新获取。 | 保持 |
| 链接已过期 | 链接已过期 / …请联系顾问重新生成。 | 保持 |
| 问卷已提交（重复访问） | 问卷已提交 / 该链接已使用过（问卷已提交），无需重复作答。 | 保持（去掉登录按钮） |

### [P2-2] 管理端问卷任务页术语与动作名不一致

- 位置：`templates/questionnaires/assignments.html`
- 修复点：
  1. 副标题"确认后进入分发（链接 / 账号）"与列头"发放方式" → 统一"分发"：列头改"分发方式"
  2. 行内"确认发送"与弹窗"确认并分发" → 统一"确认并分发"
  3. 「来源」列徽章值：`识别` → `系统推荐`，`人工` → `人工创建`（JS 里的 `a.source === 'auto' ? '识别' : '人工'`，约 line 63）
  4. 「重置密码」确认弹窗 "重置该学生账号密码？" → "重置后旧密码立即失效，新密码只显示一次，请复制后再关闭。"（主按钮文字复述动作："重置密码"）
  5. 「驳回」确认 "确认驳回该任务？" → 主按钮文字用"驳回任务"而非泛化的"确认"（先核实现状按钮文字，再统一）

### [P2-3] 学生端 JSON 错误文案去内部词

- 位置：`blueprints/questionnaires.py` line 461-473 的 JSON 分支（`"链接无效"` / `"该链接已使用"` / `"任务不存在"` / `"问卷不存在"` / `"答案校验未通过"`）
- 修复：这些文案会经 q_form 的内联横幅（P1-2 后）直接展示给学生，改为：
  - "该链接已使用" → "该链接已完成作答，不能重复提交"
  - "任务不存在" / "问卷不存在" → "链接已失效，请联系顾问"
  - "答案校验未通过" → "还有题目需要完成"（details 由 errors 列表承载）
